WLED GIF Player 16×8

Choose a GIF on your phone and stream its 128 pixels to WLED on your local Wi-Fi.

Brightness is applied to the pixel colours before each frame is sent. Slider 1% maps to 10% output, so dim settings remain visible.

Status
Choose a GIF to begin. Your phone and WLED must be on the same Wi-Fi network.

Note: browsers cannot send raw UDP. This page uses WLED's HTTP JSON API to send each frame as 128 RGB color arrays (the documented individual-LED format), so it may run slower than the PC UDP player. HTTPS-hosted pages can be blocked from contacting WLED's local HTTP address by browser security; see the included README if that happens.
